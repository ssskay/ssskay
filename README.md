# Hi, I'm Sara 👋

`she/her` · Applied AI engineer @ IBM (HashiCorp) · Boston · published researcher · maker 🐹

I'm a data hoarder, and I use it to fix problems that come up in my own life. When something gets annoying, I start collecting the data on it until I can fix it:

- My music library was full of songs called "Track 01" by unknown artist, so I built [earditor](https://github.com/ssskay/earditor) to fill in what's missing.
- I couldn't remember what was on which shelf of my storage unit, so I built a 3D dollhouse of it that maps every shelf and lights up the ones holding things I've sold and need to ship.
- I kept missing manga releases, so I built a calendar of every one of them.

Same goes for web pages I don't want to lose, every version of a story, and everything I've ever ordered. I also research other collectors: adults who buy toys and collectibles, and why.

## 📚 Catalogs

### 📅 [mangarelease](https://github.com/mangarelease/mangarelease.github.io) · [open the calendar →](https://mangarelease.github.io)

Every licensed English manga, manhwa, manhua and webtoon release in one calendar, plus a full archive of past releases. GitHub Actions scrapes 15+ publishers every day and redeploys on its own. The data is open CSV and JSON for anyone to build on. Forked from [LNRelease](https://github.com/LNRelease/lnrelease.github.io) (MIT) and extended with the API, ISBN backfill, tagging and tests.

### 🎁 [freestuff-template](https://github.com/ssskay/freestuff-template)

A catalog of the free perks students and alumni already pay for and never hear about: searchable list, campus map, and a weekly audit that opens a GitHub issue when links go stale. Astro + Supabase on Vercel. Running for [Dartmouth](https://github.com/ssskay/freestuff-dartmouth-v2) and [Carnegie Mellon](https://github.com/ssskay/freestuff-cmu). Fork it for your school.

## 🗄️ Archives

### 🏛️ [internet-historian](https://github.com/ssskay/internet-historian)

Saves web pages to the Wayback Machine from your Mac and keeps retrying through Internet Archive outages until they're actually saved. Point it at a list of pages and leave it running. `pipx install internet-historian`

### 📦 [inbox-catalog](https://github.com/ssskay/inbox-catalog)

Turns your order-confirmation emails into a structured record of everything you've bought: group purchases by project, track spending in your own categories, check whether you already own something before you buy it again. Local and read-only. Installs as a Claude Code plugin with a zero-setup demo.

### 🐰 Desktop pets, ported to macOS

Cute Windows-only desktop apps rebuilt for the Mac so they don't get left behind, with fixes sent back upstream where I can.

- [Yaha-Pet for macOS](https://github.com/ssskay/Yaha-Pet) — port of [gitChara-dot's Yaha-Pet](https://github.com/gitChara-dot/Yaha-Pet) (MIT). Usagi, Hachiware and Chiikawa wander your desktop and live in your Dock. Crash and animation fixes [offered upstream](https://github.com/gitChara-dot/Yaha-Pet/pull/2).
- [Desktop Chiikawa for macOS](https://github.com/ssskay/desktop-chiikawa-macos) — port of [CookieElmo's Desktop Chiikawa](https://cookieelmo.itch.io/desktop-chiikawa) on the native Godot runtime, with wandering, petting, snacks and kaomoji speech added. It reminds you to drink water.
